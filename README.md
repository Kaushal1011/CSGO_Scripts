## Prerequisites

- Python 3.6 or higher
- pip (Python package manager)
- Administrator/Root privileges (required for keyboard and mouse control)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Kaushal1011/CSGO_Scripts.git
   cd CSGO_Scripts
   ```

2. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

### Trigger Bot

Automatically shoots in-game when you aim at an enemy and press one of the following keys:

- **Left Shift** or
- **Left Ctrl** or
- **A + D** (simultaneously)

**Note:** This script is probably outdated and will not be updated unless requested.

### Bunny Hop

Automatically performs bunny hopping in-game when you press **Alt**.

To run the Bunny Hop script:
```bash
python Bhop.py
```

Press and hold **Left Alt** to start bunny hopping. Release to stop.
